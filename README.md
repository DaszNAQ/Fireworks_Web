# 🎆 FireWorks

A smooth, beautiful automatic firework animation — built with Vanilla JavaScript + Canvas 2D, no external libraries.

Just open the page and fireworks launch automatically. Click anywhere to launch more.

## Features

- Auto-launching fireworks, click to launch more
- 12 different explosion styles with random colors
- Launch and explosion sounds, smoke and glow effects
- Smooth performance, optimized to avoid lag

## Getting Started

Just open `index.html` directly in your browser — no installation needed.

## Built With

HTML5 Canvas, Vanilla JavaScript, Web Audio API.
